# คลังเฉลยข้อสอบ กว. สาขาโยธา

เว็บค้นหาเฉลยข้อสอบ (ไฟล์เดียว + โฟลเดอร์รูป) ใช้งานได้บนมือถือและแท็บเล็ต

## โครงสร้าง
- `index.html` แอปหลัก (ฝังข้อมูลทั้งหมดไว้ในไฟล์เดียว)
- `img/` รูปต้นฉบับเฉพาะข้อที่ตีความไม่ได้หรือไม่มีเฉลย (เปิดดูได้จากปุ่ม "ดูรูปต้นฉบับ" ในการ์ดของข้อนั้น)
- `.nojekyll`, `robots.txt` (ขอไม่ให้เสิร์ชเอนจินเก็บหน้าเว็บ)

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (รวมโฟลเดอร์ `img`) ด้วย GitHub Desktop หรือคำสั่ง git
   (อัปโหลดผ่านหน้าเว็บ GitHub ได้ครั้งละไม่เกิน 100 ไฟล์ จึงไม่เหมาะกับโฟลเดอร์ `img` ที่มีกว่า 1,300 ไฟล์)
3. ไปที่ Settings → Pages แล้วเลือกเผยแพร่จากสาขา `main` โฟลเดอร์ root
4. เปิดลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

คำสั่ง git ตัวอย่าง:
```
git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin https://github.com/ชื่อผู้ใช้/ชื่อrepo.git
git push -u origin main
```

## ข้อควรระวัง
- ข้อสอบเป็นของสภาวิศวกรและมีลายน้ำสงวนลิขสิทธิ์ repository แบบ public หมายถึงใครก็เปิดดูข้อสอบและรูปได้ ควรพิจารณาก่อนเผยแพร่
- เฉลยที่ติดป้าย "Claude คำนวณ" หรือ "OCR" ไม่ใช่เฉลยของสภาวิศวกร ควรตรวจกับรูปต้นฉบับ
