# คลังเฉลยข้อสอบ กว. สาขาโยธา

เว็บค้นหาเฉลยข้อสอบ ใช้ได้บนคอมพิวเตอร์ มือถือ และแท็บเล็ต ทำงานได้แม้ออฟไลน์หลังเปิดครั้งแรก

## ฟีเจอร์
- ค้นหาจากคำในโจทย์หรือตัวเลือก (ไม่สนไม้เอก ไม้โท ช่องว่าง) กรองตามวิชา ไฟล์ เลขข้อ
- **ค้นด้วยรูปโจทย์**: กด 📷, ลากรูปมาวาง หรือแคปหน้าจอแล้วกด Ctrl+V ตัวอ่านข้อความทำงานในเบราว์เซอร์เอง (ไม่อัปโหลดรูป)
- **โหมดสอบจำลอง**: สุ่มข้อ ตั้งเวลาได้ สรุปคะแนนรายวิชา จำข้อที่ผิดไว้ฝึกซ้ำ พร้อมสถิติสะสม
- โหมดฝึกทำแบบเฉลยทันที บันทึกข้อด้วยดาว คัดลอกข้อความ/ลิงก์รายข้อ
- โหมดสว่าง/มืด และติดตั้งเป็นแอปบนมือถือได้ (Add to Home Screen)
- รูปต้นฉบับของข้อที่ตีความไม่ได้หรือไม่มีเฉลย (ปุ่ม "ดูรูปต้นฉบับ")

## โครงสร้าง
- `index.html` แอปหลัก (ข้อมูลทั้งหมดฝังอยู่ในไฟล์)
- `img/` รูปต้นฉบับเฉพาะข้อที่จำเป็น
- `vendor/` ตัวอ่านข้อความ (tesseract.js) และข้อมูลภาษาไทย/อังกฤษ
- `sw.js`, `manifest.webmanifest`, `icon-*.png` สำหรับใช้ออฟไลน์และติดตั้งเป็นแอป
- `.nojekyll`, `robots.txt`

## อัปเดตเว็บที่มีอยู่แล้ว
ลบไฟล์และโฟลเดอร์เก่าใน repository (โดยเฉพาะ `img`) แล้ววางชุดใหม่ จากนั้น Commit และ Push ใน GitHub Desktop

## ขึ้น GitHub Pages
1. สร้าง repository แล้ว clone ลงเครื่องด้วย GitHub Desktop
2. คัดลอกไฟล์ในโฟลเดอร์นี้ไปวาง Commit และ Push
3. Settings → Pages → เลือกสาขา `main` โฟลเดอร์ `/ (root)` → Save

## ข้อควรระวัง
- ต้องเปิดผ่านลิงก์เว็บ (https) ตัวอ่านรูปและโหมดออฟไลน์จึงจะทำงาน
- ข้อสอบเป็นของสภาวิศวกรและมีลายน้ำสงวนลิขสิทธิ์ repository แบบ public หมายถึงใครก็เปิดดูข้อสอบและรูปได้
- เฉลยที่ติดป้าย "Claude คำนวณ" ไม่ใช่เฉลยของสภาวิศวกร ควรตรวจกับรูปต้นฉบับ
