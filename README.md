# คลังเฉลยข้อสอบ กว. สาขาโยธา (เวอร์ชัน 5.0)

เว็บแอปค้นหาเฉลยข้อสอบ ใช้ได้บนคอมพิวเตอร์ มือถือ และแท็บเล็ต ทำงานได้แม้ออฟไลน์หลังเปิดครั้งแรก

## ฟีเจอร์
- **หน้าหลัก** สรุปจำนวนข้อ ความคืบหน้า จำนวนวันติดต่อกัน เลือกตามวิชา (23 วิชา)
- **ค้นหา** จากคำในโจทย์หรือตัวเลือก (ไม่สนไม้เอก ไม้โท ช่องว่าง) กรองตามไฟล์ วิชา เลขข้อ สถานะเฉลย
- **ค้นด้วยรูปโจทย์** กด 📷 ลากรูปมาวาง หรือแคปหน้าจอแล้วกด Ctrl+V ตัวอ่านข้อความทำงานในเบราว์เซอร์เอง ไม่อัปโหลดรูป
- **ฝึกทำ / สอบจำลอง** สุ่มข้อ ตั้งเวลาได้ สรุปคะแนนรายวิชา
- **ทบทวนตามรอบ** ข้อที่ตอบผิดกลับมาทบทวนที่ 1, 3, 7, 14, 30 วัน
- **ถาม AI** เมื่อข้อไม่อยู่ในคลัง: แชทด้วยคีย์ฟรีของคุณเอง (Gemini / OpenRouter / Groq) หรือคัดลอกโจทย์ไปวางใน ChatGPT, Gemini, Claude
- **ตั้งค่า** ธีมสว่าง/มืด ขนาดตัวอักษร สำรองและกู้คืนข้อมูล
- ปุ่มลัดคีย์บอร์ด (กด `?`), คัดลอกข้อความ/ลิงก์รายข้อ, ปุ่มแจ้งข้อผิด (เปิด GitHub Issues), ติดตั้งเป็นแอปบนมือถือได้

## โครงสร้างไฟล์
- `index.html` แอปหลัก (ข้อมูลข้อสอบทั้งหมดฝังอยู่ในไฟล์)
- `img/` รูปต้นฉบับเฉพาะข้อที่ตีความไม่ได้หรือไม่มีเฉลย
- `vendor/` ตัวอ่านข้อความ (tesseract.js) และข้อมูลภาษาไทย/อังกฤษ
- `fonts/` ฟอนต์ Sarabun
- `sw.js`, `manifest.webmanifest`, `icon-*.png` สำหรับใช้ออฟไลน์และติดตั้งเป็นแอป
- `.nojekyll`, `robots.txt`

## อัปเดตเว็บที่มีอยู่แล้ว
1. เปิดโฟลเดอร์ repository ที่ GitHub Desktop ดึงไว้ **ลบไฟล์และโฟลเดอร์เก่าทั้งหมด** (ยกเว้นโฟลเดอร์ `.git`)
2. คัดลอกไฟล์จากชุดใหม่ไปวาง (ชุดนี้มีโฟลเดอร์ `fonts` เพิ่มเข้ามา)
3. GitHub Desktop → Commit → Push origin → รอ 1–2 นาที แล้วรีเฟรชเว็บ (ผู้ใช้ที่เคยเปิดแล้วจะเห็นแถบ "มีเวอร์ชันใหม่" ให้กดโหลดใหม่)

## ขึ้น GitHub Pages ครั้งแรก
1. สร้าง repository แล้ว clone ลงเครื่องด้วย GitHub Desktop
2. คัดลอกไฟล์ในโฟลเดอร์นี้ไปวาง Commit และ Push
3. Settings → Pages → เลือกสาขา `main` โฟลเดอร์ `/ (root)` → Save

## เรื่องคีย์ AI (สำคัญ)
- ไม่มีคีย์ AI ของผู้สร้างเว็บอยู่ในไฟล์เหล่านี้ เพราะ repository แบบ public จะถูกขโมยคีย์ได้ ผู้ใช้แต่ละคนใส่คีย์ของตัวเอง เก็บในเบราว์เซอร์ของเขาเท่านั้น
- ระดับฟรีมีจำกัดจำนวนครั้ง เงื่อนไขเปลี่ยนได้ และบางผู้ให้บริการอาจนำข้อความไปปรับปรุงผลิตภัณฑ์ อย่าใส่ข้อมูลส่วนตัว
- AI คำนวณผิดได้ ตรวจเทียบกับเฉลยในคลังเสมอ

## ความเป็นส่วนตัว
ไม่มีระบบติดตามผู้ใช้ ไม่ใช้คุกกี้ สถิติและข้อที่บันทึกเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ไฟล์ทั้งหมดโหลดจากเว็บนี้เอง ข้อมูลออกจากเครื่องก็ต่อเมื่อผู้ใช้สั่งใช้แชท AI หรือเปิดลิงก์แจ้งข้อผิด

## ข้อควรระวัง
- ต้องเปิดผ่านลิงก์เว็บ (https) ตัวอ่านรูปและโหมดออฟไลน์จึงจะทำงาน
- ข้อสอบเป็นของสภาวิศวกรและมีลายน้ำสงวนลิขสิทธิ์ repository แบบ public หมายถึงใครก็เปิดดูข้อสอบและรูปได้
- เฉลยที่ติดป้าย "Claude คำนวณ" ไม่ใช่เฉลยของสภาวิศวกร ควรตรวจกับรูปต้นฉบับ
- ข้อความเฉลยที่ผ่านการถอดจากภาพสแกนโดย Claude ผ่านการตรวจเทียบภาพแล้ว แต่ยังไม่ผ่านผู้เชี่ยวชาญ
